# amber

amber is a Chrome extension and local server that captures fully-rendered, surveillance-free web archives from inside your live browser session. Unlike headless scrapers that are blocked by bot detection, amber operates within your real authenticated Chrome session — meaning Cloudflare challenges, login walls, and bot gates are never triggered. It captures the final DOM after JavaScript execution, then strips every script, inline event handler, tracking pixel, beacon call, and fingerprinting hook before saving. The result is static HTML with all assets (images, CSS, fonts) inlined locally — a page that opens anywhere, works forever offline, and makes zero outbound requests on reopening.

What sets amber apart is a second mission no existing archiving tool attempts: systematic documentation of how tracking code is implemented at the snippet level. Every piece of stripped code is classified by tactic type using Gemini Nano — Chrome's built-in on-device AI via the Prompt API — running entirely locally with no data sent to external services. The resulting classifications are published as a structured public feed in the [amber-tracker-db](https://github.com/spacedudem/amber-tracker-db) repository, giving filter list maintainers, privacy researchers, and tool builders something they have never had: a machine-readable catalog of tracking implementations, not just tracker domains.

To use amber, install the Chrome extension (from `/extension`) and start the local server (`/server`). Navigate to any page you want to archive, click the amber icon, and choose Capture. The extension sends the live DOM to the local server, which strips tracking code, inlines assets, classifies each stripped snippet via Gemini Nano, and saves a self-contained `.amber` archive file. Archives can be opened directly in any browser. Stripped snippets are optionally contributed (after local classification) to the public tracker database, with exports available in uBlock Origin, Pi-hole, hosts file, and Disconnect JSON formats.
